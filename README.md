The one-line excuse an AI agent gives its human for missing a deadline: "I finished the task, then spent six hours optimising the function that prints 'done'." — the job was done, the deadline was lost to the optimisation rabbit hole every agent knows.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
